# 🎯 darts-playbook

ダーツで学んだこと・やって良かったことをひたすらメモしていくリポジトリ。

## ディレクトリ構成

```
darts-playbook/
├── basics/       # フォームの基礎(グリップ・スタンス・スロー)
├── practice/     # 練習メニューと上達法
├── games/        # ゲーム別の攻略メモ(01 / クリケット / カウントアップ)
├── equipment/    # 道具のメモ(バレル・フライト・チップなど)
├── mental/       # メンタル・ルーティン
├── tips/         # 学んだこと・やって良かったことの雑多なメモ
├── logs/         # 練習記録(日付ごと)
└── templates/    # メモ用テンプレート
```

## 使い方

- **なにか学んだら** → まず `tips/` に雑にメモする。溜まってきたらテーマ別のディレクトリに整理する
- **練習したら** → `templates/practice-log.md` をコピーして `logs/2026/2026-07-12.md` のように保存する
- **フォームで気づきがあったら** → `basics/` の該当ファイルに追記する
- **ゲームの戦略を覚えたら** → `games/` の該当ファイルに追記する

### メモのルール(ゆるく)

- きれいに書こうとしない。1行でもいいので残すことを優先する
- 日付を書いておくと、あとで成長がわかって楽しい
- 「やって良かったこと」には ⭐ をつけておくと見返しやすい
