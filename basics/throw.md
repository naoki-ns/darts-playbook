# スロー(テイクバック〜リリース〜フォロースルー)

投げ方に関する気づきのメモ。

## 現在の課題(2026-07-13時点)

- 縦のブレが大きい(横ブレは脱力でかなり抑えられるようになった)

→ ブレの切り分けが進んだ。横 = 力み、縦 = 肘上げ押し出し・手首の振り切りの抜け、と原因が見えてきた。

## 意識していること

- 脱力(横ブレ対策)+ 矢先の意識
- **肘上げ押し出し + 手首の振り切りを同時に**(縦ブレ対策)。片方だけ意識するともう片方が抜ける

## 学んだこと

<!-- 例: 2026-07-12 フォロースルーで手を狙いに向けて伸ばすと縦のブレが減った ⭐ -->

- 2026-07-12 **力むとブレる** ⭐ お店で縦横に散ってブルに入らない日、力みが原因だと気づいた。テイクバック・リリースまわりに力が入っていた
- 2026-07-13 **脱力で横ブレが抑えられた** ⭐ 前日の気づきを実践して効果を確認
- 2026-07-13 **縦ブレは「肘上げ押し出し」と「手首の振り切り」を同時にやらないと消えない** ⭐ 片方だけだともう片方が抜ける。肘上げ押し出しを忘れると下ブレ、振り切りを忘れると弾道がふわっと浮いて矢速不足で上下が運任せになる

## うまくいかない時のチェックリスト

<!-- 調子が悪い時に見返す用。原因と対処をセットで書く -->

- 縦横に散る・ブルに入らない → まず力みを疑う。グリップと腕を脱力して1スロー投げてみる(2026-07-12)
- 横に散る → 力み。脱力すると抑えられる(2026-07-13 効果確認済み)
- 下にブレる → リリース時の「肘上げ押し出し」が抜けていないか確認(2026-07-13)
- 弾道がふわっと浮いて上下が安定しない → 手首の振り切りが抜けて矢速が落ちていないか確認(2026-07-13)
- 下ブレが続いて力み始めたら悪循環のサイン: 下ブレ → 力む → 左右・上へのブレが悪化。一度脱力に戻る(2026-07-13)
